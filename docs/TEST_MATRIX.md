# Test matrix

The contract test plan covers wrong caller, malformed HTTPS/hash input, policy bounds, immutable acceptance, hash mismatch, validator disagreement, low-confidence fail-safe mapping, unavailable evidence, deadline/replay guards, exact deposit, early settlement, wrong beneficiary and conservation. Frontend tests cover local SHA-256, URL/hash mismatch, wallet rejection, wrong network, finality/readback and mobile comparison layout. Live tests are opt-in and must use a funded Studionet wallet supplied outside the repository.
