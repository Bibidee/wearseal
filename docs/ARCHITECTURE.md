# Architecture

`WearsealAgreement` owns parties, immutable policy, image commitments, bounded multimodal consensus, lifecycle, and settlement instructions on GenLayer Studionet. `WearsealVault` is a Studionet accounting mirror: it records external funding and finalized claim transaction hashes only when an explicitly configured attestor submits them. The attestor is an operator trust boundary: the server verifies the Base Sepolia receipt, destination, calldata, sender, event and amount before submitting the GenLayer acknowledgement. `WearSealEscrow` on Base Sepolia holds native ETH, requires a relayer registration derived from Agreement state before accepting the exact renter deposit, receives one exact payout allocation, and lets each recipient pull their own payout atomically. The browser is a wallet client and evidence preparation surface; both chains are authoritative for their respective state.
